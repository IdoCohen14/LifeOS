איזה גיבוי להחזיר?

בחרו גיבוי שמור או קובץ מוצפן מתיקייה אחרת. הקובץ מועבר רק לכלי השחזור המקומי, ללא שירות חיצוני.

הבדיקה אינה מחליפה נתונים. הסיסמה מתנקה לאחר כל ניסיון.

השחזור יחליף את הנתונים וסיסמת הכניסה באלה שהיו בגיבוי. לפני ההחלפה ייווצר גיבוי בטיחות מוצפן של המצב הנוכחי, עם אותה סיסמת גיבוי. יהיה צורך להיכנס מחדש; התראות Push וגיבוי אוטומטי יישארו כבויים.

הבדיקה תקפה ל־10 דקות. אם הקובץ השתנה תידרש בדיקה חדשה.

השחזור הושלם

אפשר לסגור את חלון השחזור ולהפעיל שוב את LifeOS. היכנסו עם סיסמת האפליקציה שהייתה בזמן הגיבוי.

ייתכן שיידרש חיבור מחדש ל־Google או Moodle בפרופיל Windows או במחשב אחר.

הכל נשאר במחשב הזה. השחזור אינו מעלה נתונים לשירות חיצוני.
